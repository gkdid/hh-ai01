- 갈등 상황에서 **내 감정을 알아차리고 말로 해결**할 수 있다.

## 기분이 나빠지는 순간

내 감정을 알아차려 봅시다

쉬는 시간입니다. **주은**이가 **하은**이에게 대뜸 말했습니다. "야, 너 왜 그런 옷을 입었어? 좀 이상해." 하은이는 아무 말도 하지 못했습니다. 그런데 가슴이 답답하고 눈물이 날 것 같았습니다.

주은

"야, 너 왜 그런 옷을 입었어? 좀 이상해."

(아무 말도 못 하고 고개를 숙인다)

하은

하영

"하은아, 괜찮아? 기분이 나빠 보여."

"응, 조금 속상했어."

하은

### 연습해 봅시다

1

친구의 **기분을 상하게 하는 말**에 ○ 해 봅시다. (여러 개 골라도 좋아요)

"너 오늘 예쁘다." "그런 것도 몰라?" "같이 놀자." "네가 그래서 친구가 없어." "도와줘서 고마워." "야, 저리 가."

2

내가 기분이 나빠졌을 때 **내 몸은 어떻게 반응**하나요? 해당되는 것에 ○ 해 봅시다.

- □ 가슴이 답답해진다
- □ 얼굴이 뜨거워진다
- □ 목소리가 커진다
- □ 눈물이 난다
- □ 손이 떨린다
- □ 머리가 복잡해진다

3

오늘 또는 최근에 **속상했던 일**을 한 가지 써 봅시다.

## 화가 날 때의 나

터트리지 않고 가라앉혀요

**채원**이가 아끼던 펜을 **주현**이에게 빌려주었습니다. 그런데 다음 날 돌려받아 보니 펜 뚜껑이 부러져 있었습니다. 채원이는 너무 화가 나서 책상을 '쾅!' 쳤습니다.

채원

"야! 너 왜 내 펜 망가뜨렸어?!"

"어... 그럴 리가. 잘 썼는데."

주현

채원

"빌려줬더니 이렇게 만들다니!"

"채원아, 잠깐. 심호흡 한 번 하고 이야기해 보자."

선생님

1

화가 날 때 할 수 있는 **좋은 방법**과 **안 좋은 방법**을 구분해 봅시다.

| 행동 | 좋은 방법 | 안 좋은 방법 |
|---|---|---|
| 깊게 숨을 들이마신다 | | |
| 책상을 주먹으로 친다 | | |
| 잠시 자리를 벗어나 진정한다 | | |

| 물 한 컵을 천천히 마신다 | | |
| 선생님께 도움을 요청한다 | | |

2

화를 가라앉히는 **나만의 방법**을 세 가지 써 봅시다.

3

**나.** 모둠 활동에서 내 의견이 무시당했을 때

## 말로 해결하기

"나-전달법"으로 마음을 전해요

복도에서 **예은**이가 큰 소리로 이야기하는 바람에 공부하던 **주현**이가 집중이 되지 않습니다. 주현이는 어떻게 말하면 좋을까요?

주현

(안 좋은 예) "야, 시끄러! 좀 조용히 해!"

"뭐야, 기분 나쁘게."

예은

주현

(좋은 예) "예은아, 소리가 조금 커서 내가 집중이 안 돼. 조금만 작게 말해줄래?"

"아, 미안. 몰랐어. 알겠어."

예은

> 💡 💡 나-전달법 **"너 때문에 ~"**는 상대를 탓하는 말이에요. 대신 **"나는 ~해서 ~기분이 들어"**라고 말해 보세요. 공식: **"나는 (상황)이라서 / (감정)이 들어. (바라는 것)해 주면 좋겠어."**

### 연습해 봅시다

1

'너-전달법' 문장을 **'나-전달법'**으로 바꿔 써 봅시다.

**가.** "너 때문에 숙제 망했잖아!" →

**나.** "왜 그렇게 느리게 해?" →

**다.** "네가 시끄러워서 짜증나." →

2

빈칸을 채워 **나-전달법 문장**을 완성해 봅시다.

"나는 ____ 해서 ____ 기분이 들어. ____ 해 주면 좋겠어."

3

다음 상황에서 **내가 쓸 나-전달법 문장**을 만들어 봅시다.

**가.** 친구가 내 자리에 앉아 있을 때

**나.** 친구가 허락 없이 내 간식을 먹었을 때

## 사과와 화해

다툰 후에도 다시 가까워질 수 있어요

어제 **하은**이와 **하영**이가 작은 일로 말다툼을 했습니다. 오늘 아침, 하영이는 마음이 편하지 않습니다. 하영이는 용기를 내어 하은이에게 다가갑니다.

하영

"하은아, 어제 내가 말을 심하게 해서 미안해."

"...음."

하은

하영

"네 기분을 생각하지 못했어. 앞으로는 더 조심할게."

"응. 나도 어제 좀 예민했어. 미안해. 우리 화해하자."

하은

> 💡 💡 사과의 네 가지 재료 ① 무엇을 잘못했는지 **말하기** · ② "미안해"라고 **분명히 말하기** · ③ 상대의 **기분 인정하기** · ④ 앞으로의 **약속**

### 연습해 봅시다

1

**좋은 사과**와 **그렇지 않은 사과**를 구분해 봅시다.

| 사과의 말 | 좋은 사과 | 그렇지 않은 사과 |
|---|---|---|
| "미안하긴 한데, 너도 잘못했잖아." | | |
| "내가 큰 소리로 말해서 미안해." | | |
| "알겠어, 미안." | | |
| "네 기분을 생각 못 해서 미안. 다음엔 조심할게." | | |
| "뭐 어때, 별일도 아닌데." | | |

2

아래 상황에서 **내가 할 사과의 말**을 써 봅시다.

**가.** 내가 화나서 친구에게 심한 말을 했을 때

**나.** 실수로 친구의 물건을 망가뜨렸을 때

3

친구가 나에게 사과했을 때 내가 해 줄 **용서의 말** 세 가지를 써 봅시다.

## 내 물건 · 남의 물건

모든 물건에는 '주인'이 있어요

선생님이 잠시 자리를 비우셨습니다. **주은**이가 선생님 책상 위의 예쁜 스티커를 발견했습니다. 구경이라도 해보고 싶어서 손을 뻗는데, 마침 **하영**이가 다가옵니다.

하영

"주은아, 그건 선생님 물건이야. 허락 없이 만지면 안 돼."

"어? 그냥 구경만 하려고 했어."

주은

하영

"구경도 주인이 있을 때 물어보고 해야 하는 거야."

"아, 그렇구나. 알겠어. 고마워."

주은

> 💡 💡 물건의 주인 **내 것**: 내가 사거나 받은 것 · **친구 것**: 친구가 사거나 받은 것 · **선생님·학교 것**: 함께 쓰지만 반드시 허락이 필요한 것 → 주인이 아니면 **허락 없이 만지거나 가져가지 않기**!

### 연습해 봅시다

1

다음 물건의 **주인**을 써 봅시다.

| 물건 | 주인 |
|---|---|
| 하영이의 필통 | |
| 교실의 국어사전 | |
| 선생님 책상의 컵 | |
| 내 이름이 적힌 공책 | |
| 도서실의 책 | |

2

'허락이 **필요 없는 것**'과 '허락이 **필요한 것**'을 구분해 봅시다.

| 물건 | 허락 필요 없음 | 허락 필요함 |
|---|---|---|
| 내 책 | | |
| 친구의 필통 | | |
| 내 가방 속 물건 | | |
| 선생님의 노트북 | | |
| 교실 청소 도구(공용) | | |

3

친구의 물건을 만져 보고 싶을 때 할 말을 완성해 봅시다.

"**(친구 이름)**아, ____ 한 번 ____ 봐도 될까?"

## 빌리기의 약속

바르게 빌리는 네 가지 단계

수업 시간입니다. **주은**이가 연필이 없어서 필기를 못 하고 있습니다. 옆자리 **하영**이에게 연필을 빌리고 싶습니다. 어떻게 말하면 좋을까요?

주은

"하영아, 혹시 연필 하나만 빌려줄 수 있어?"

"응, 그래. 이거 쓸래?"

하영

주은

"고마워! 꼭 잘 쓰고 돌려줄게."

(수업 후) "연필 돌려줄게. 덕분에 잘 썼어, 고마워!"

주은

> 💡 💡 빌리기의 네 단계 ① **허락 구하기** — "빌려줄 수 있어?" · ② **잘 쓰기** — 망가뜨리지 않기 · ③ **돌려주기** — 약속한 때에 · ④ **고마움 표현** — "고마워"

### 연습해 봅시다

1

바른 빌리기의 **순서**를 정해 봅시다.

**ㄱ.** "잘 썼어, 고마워." 하고 감사를 전한다.

**ㄴ.** "빌려줄 수 있어?" 하고 허락을 구한다.

**ㄷ.** 빌린 물건을 조심해서 쓴다.

**ㄹ.** 약속한 때에 돌려준다.

순서: ( ) → ( ) → ( ) → ( )

2

친구의 물건을 빌렸을 때 **꼭 지켜야 할 약속**을 세 가지 써 봅시다.

3

다음 상황에서 **빌리기의 말**을 만들어 봅시다.

**가.** 체육시간에 친구에게 공을 빌리고 싶을 때

**나.** 친구의 책을 하루만 빌려 읽고 싶을 때

## "갖고 싶어"를 이기는 법

유혹 앞에서 나를 지켜요

**채원**이는 며칠 전부터 **예은**이의 새 필통이 마음에 쏙 듭니다. 쉬는 시간, 예은이가 자리를 비웠고 교실에는 아무도 없습니다. 채원이의 마음에 두 가지 생각이 떠오릅니다.

마음 A

"한 번만 써 보면 안 될까? 아무도 안 볼 거야."

"안 돼. 주인이 없을 때 남의 물건을 만지는 건 옳지 않아."

마음 B

마음 A

"한 번만 쓰고 놓으면 아무도 모를 텐데..."

"아무도 몰라도, **나는 알아**. 부러우면 말로 표현하면 돼."

마음 B

> 💡 💡 유혹을 이기는 세 문장 "아무도 몰라도, **나는 안다.**" · "부러우면 **말로 표현**하자." · "갖고 싶으면 **용돈을 모으자.**"

### 연습해 봅시다

1

'갖고 싶은 마음'이 들 때, 나를 도와주는 **바른 생각**에 ○ 해 봅시다.

- □ "주인이 없어도 안 돼."
- □ "한 번만 써 보면 괜찮아."
- □ "허락을 구하면 된다."
- □ "아무도 안 보면 된다."
- □ "용돈을 모아서 사자."
- □ "부럽다고 말하면 된다."

2

'갖고 싶은 마음'을 이기는 **나만의 방법**을 세 가지 써 봅시다.

3

친구 물건을 허락 없이 **가져가면 안 되는 이유**를 두 가지 써 봅시다.

## 물건을 잃어버렸을 때

당황하지 말고 침착하게!

수업이 끝난 뒤 **하영**이가 가방을 열어 보니 **지갑**이 보이지 않습니다. 아침에 분명히 넣어 왔는데... 하영이는 당황해서 얼굴이 하얗게 됩니다.

하영

(속으로) "어떡하지... 분명히 있었는데..."

"하영아, 무슨 일 있어?"

하은

하영

"지갑이 없어졌어..."

"침착해. 먼저 찾아보고, 선생님께 말씀드리자."

하은

선생님

"하영아, 걱정 마. 함께 찾아보자. 이런 일은 선생님께 바로 이야기하는 게 가장 좋아."

> 💡 💡 네 단계 대처법 ① **침착하게 다시 찾기** (가방·사물함·자리 주변) · ② **선생님께 알리기** · ③ **친구를 의심하지 말고** "혹시 봤어?" 물어보기 · ④ 선생님과 함께 **해결 방법 찾기**

### 연습해 봅시다

1

물건을 잃어버렸을 때 해야 할 **순서**를 정해 봅시다.

**ㄱ.** 선생님께 말씀드린다.

**ㄴ.** 침착하게 다시 찾아본다.

**ㄷ.** 친구들에게 "혹시 봤어?" 물어본다.

**ㄹ.** 먼저 심호흡을 한다.

순서: ( ) → ( ) → ( ) → ( )

2

잃어버렸을 때의 **바른 행동**과 **안 좋은 행동**을 구분해 봅시다.

| 행동 | 바른 행동 | 안 좋은 행동 |
|---|---|---|
| 소리 지르며 울기 | | |
| 선생님께 먼저 말씀드리기 | | |
| 특정 친구를 몰래 째려보기 | | |
| 가방과 사물함을 다시 살펴보기 | | |
| "너 가져갔지?" 하고 몰아세우기 | | |

3
