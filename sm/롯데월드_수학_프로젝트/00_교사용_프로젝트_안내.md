# 📘 우리 함께 롯데월드로! — 수학 프로젝트 학습

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| **주제** | 롯데월드 현장체험학습 계획하기 |
| **대상** | 고등학교 특수교육대상학생 |
| **차시** | 총 4차시 (차시당 40~50분) |
| **등장인물** | 하영, 하은, 주은, 주현, 채원, 예은 (6명) + 선생님 |
| **핵심 개념** | 복지카드 사용, 돈 계산, 예산 관리 |

## 2. 학습 목표

1. 복지카드의 뜻과 사용 방법을 안다.
2. 복지카드 할인(50%)이 적용된 요금을 계산할 수 있다.
3. 주어진 예산 안에서 음식과 기념품을 계획할 수 있다.
4. 하루 전체 비용을 항목별로 정리하고 합산할 수 있다.

## 3. 차시별 구성

| 차시 | 주제 | 주요 수학 활동 |
|---|---|---|
| **1차시** | 입장권 요금 계산하기 | 50% 할인 계산, 여러 명 요금 합산 |
| **2차시** | 점심 식사 계획하기 | 메뉴 가격 합산, 예산 내 선택 |
| **3차시** | 기념품 사기 | 물건값 합산, 거스름돈 계산 |
| **4차시** | 하루 총비용 정리 | 항목별 합산, 절약한 금액 계산 |

## 4. 등장인물 설정

> 💡 고등학교 특수학급 6명의 학생들이 선생님과 함께 롯데월드로 현장체험학습을 갑니다.
> 6명의 학생은 모두 **복지카드**를 가지고 있어서 입장권을 **반값**에 살 수 있어요.

| 이름 | 좋아하는 것 |
|---|---|
| 하영 | 꼼꼼하게 계획 세우기 |
| 하은 | 맛있는 음식 먹기 |
| 주은 | 사진 찍기 |
| 주현 | 신나는 놀이기구 타기 |
| 채원 | 예쁜 기념품 모으기 |
| 예은 | 친구들과 이야기하기 |

## 5. 복지카드 안내 (지도 참고 자료)

- **복지카드**란? 나라에서 발급하는 카드로, 가지고 있으면 여러 시설에서 요금을 할인받을 수 있어요.
- **어디서 쓸 수 있나요?** 지하철, 버스, 놀이공원, 영화관, 박물관 등에서 **요금을 깎아** 줘요.
- **롯데월드에서는?** 복지카드를 보여주면 입장권을 **반값(50% 할인)** 에 살 수 있어요. 함께 온 보호자 1명도 똑같이 할인받을 수 있어요.
- **중요**: 복지카드는 **본인만** 사용할 수 있어요. 다른 사람에게 빌려주면 안 돼요.

## 6. 지도상의 유의점

- 금액은 실제 롯데월드 요금을 단순화한 **학습용 가격**입니다. 수업 상황에 맞게 수정하세요.
- 학생 수준에 따라 계산기 사용 허용 여부를 선택합니다.
- 복지카드 사용이 **부끄러운 일이 아니며, 정당한 권리**임을 강조합니다.
- 실제 현장체험학습 전/후에 활용하면 학습 효과가 더 커집니다.

## 7. 준비물

- 학습지 (차시별 1부씩)
- 색연필 또는 사인펜
- 계산기 (필요 시)
- (선택) 실제 복지카드 또는 사진 자료
