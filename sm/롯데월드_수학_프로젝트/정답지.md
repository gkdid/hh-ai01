# 📗 정답지 (교사용)

## 🎢 1차시 — 입장권 요금

- **문제 1**: 50,000 ÷ 2 = **25,000원**
- **문제 2**: 하영~예은 모두 **각 25,000원**
- **문제 3**: 25,000 × 6 = **150,000원**
- **문제 4**: 150,000 + 60,000 = **210,000원**
- **문제 5**:
  - ① 50,000 × 6 = **300,000원**
  - ② 25,000 × 6 = **150,000원**
  - ③ 300,000 − 150,000 = **150,000원**

## 🍔 2차시 — 점심 식사

- **문제 1**: 10,000 + 3,000 = **13,000원** → 예산(15,000원)보다 **적다**
- **문제 2**:

| 이름 | 합계 |
|---|---|
| 하은 | 6,000 + 5,000 + 3,000 = **14,000원** |
| 주은 | 8,000 + 4,000 + 3,000 = **15,000원** |
| 주현 | 10,000 + 4,000 = **14,000원** |
| 채원 | 6,000 + 3,000 + 4,000 = **13,000원** |
| 예은 | 5,000 + 4,000 + 3,000 = **12,000원** |

- **문제 3**: 모두 15,000원 이하 → **예산을 지킨 친구는 6명** (주은은 정확히 15,000원으로 예산 안)
- **문제 4**: 13,000 + 14,000 + 15,000 + 14,000 + 13,000 + 12,000 = **81,000원**
- **문제 5**: 학생 자유 응답 (예산 15,000원 이내 확인)

## 🎁 3차시 — 기념품 사기

- **문제 1**: 30,000 − 20,000 = **10,000원**
- **문제 2**:
  - ① 12,000 + 2,000 = **14,000원**
  - ② 20,000 − 14,000 = **6,000원**
- **문제 3**:

| 이름 | 물건값 합계 | 거스름돈 |
|---|---|---|
| 주은 | 15,000 + 3,000 = **18,000원** | 20,000 − 18,000 = **2,000원** |
| 주현 | 18,000 + 5,000 = **23,000원** | 30,000 − 23,000 = **7,000원** |
| 채원 | 20,000 + 2,000 = **22,000원** | 30,000 − 22,000 = **8,000원** |
| 예은 | 12,000 + 5,000 + 3,000 = **20,000원** | 20,000 − 20,000 = **0원** |

- **문제 4** (10,000원으로 살 수 있는 것):

| 물건 | 판단 |
|---|---|
| 열쇠고리 (5,000원) | **○** |
| 로티 인형 (20,000원) | ✗ |
| 스티커 세트 (3,000원) | **○** |
| 캐릭터 머리띠 (15,000원) | ✗ |
| 볼펜 (2,000원) | **○** |

- **문제 5** (친구별 실제로 쓴 돈 = 물건값 합계):

| 이름 | 실제로 쓴 돈 |
|---|---|
| 하영 | 20,000원 |
| 하은 | 14,000원 |
| 주은 | 18,000원 |
| 주현 | 23,000원 |
| 채원 | 22,000원 |
| 예은 | 20,000원 |
| **합계** | **117,000원** |

- **문제 6**: 학생 자유 응답 (합계 20,000원 이내 확인)

## 🌙 4차시 — 하루 총비용 정리

- **문제 1**: 25,000 + 13,000 + 20,000 + 0 = **58,000원**
- **문제 2**:

| 이름 | 입장권 | 점심값 | 기념품 | 교통비 | 하루 합계 |
|---|---|---|---|---|---|
| 하영 | 25,000 | 13,000 | 20,000 | 0 | **58,000** |
| 하은 | 25,000 | 14,000 | 14,000 | 0 | **53,000** |
| 주은 | 25,000 | 15,000 | 18,000 | 0 | **58,000** |
| 주현 | 25,000 | 14,000 | 23,000 | 0 | **62,000** |
| 채원 | 25,000 | 13,000 | 22,000 | 0 | **60,000** |
| 예은 | 25,000 | 12,000 | 20,000 | 0 | **57,000** |

- **문제 3**: 58,000 + 53,000 + 58,000 + 62,000 + 60,000 + 57,000 = **348,000원**
- **문제 4**:
  - ① 50,000 × 6 = **300,000원**
  - ② 25,000 × 6 = **150,000원**
  - ③ 300,000 − 150,000 = **150,000원**
  - ④ 3,000 × 6 = **18,000원**
  - ⑤ 150,000 + 18,000 = **168,000원**

👉 복지카드 덕분에 학생 6명이 **총 168,000원**을 절약했습니다.
