활동 2. 하영이의 응급 대응 순서

순서

펫샵에서 강아지가 갑자기 구토·경련. 어떻게?

  1. 침착하게 주변 위험 요소 치우기
  2. 보호자·매니저 즉시 연락
  3. 24시 동물병원에 전화 → "지금 갑니다"
  4. 강아지를 담요·이동장으로 안전하게 이동
  5. 병원 도착 후 상황 상세 설명 (시각·증상·먹은 것)

3. 응급처치 기본

Step 3

활동 4. 주현이의 상처·출혈 대응

상처
  1. 깨끗한 물로 상처 씻기
  2. 깨끗한 거즈·수건으로 10분 이상 압박 지혈
  3. 강아지가 상처를 핥지 못하게 넥카라·붕대
  4. 깊거나 지혈 안 되면 병원 즉시
❗ 절대 X 소독약(과산화수소·알콜) 직접 사용 X → 세포 파괴. 세척은 생리식염수·깨끗한 물만.

활동 5. 미정이의 열사병 대응

열사병

여름·차 안에서 자주 발생. 강아지는 땀샘이 발바닥에만 있어 열 방출 어려움.

증상대응
헐떡임 심함·침 흘림시원한 그늘로 이동
잇몸 빨강·자주색미지근한(찬물 X) 물로 몸 적시기
쓰러짐·경련즉시 병원 · 에어컨 있는 차량
❗ 절대 X 얼음물·찬물 → 혈관 수축으로 오히려 위험. 여름철 차 안에 5분도 두지 마세요!

4. 병원 · 자기점검

Step 4

활동 6. 채원이의 응급 연락처

준비

펫샵·호텔·미용실에 비치해 둘 정보:

  • 가까운 동물병원 전화번호·주소
  • 24시 응급 동물병원 (밤·주말)
  • 보호자 비상 연락처 (2인 이상)
  • 강아지·고양이 기록 (품종·나이·질환·약물)
  • 이동장·담요 위치
💡 관리사의 역할 응급 시 침착하고 기록 정확히. 감정에 휘둘리지 말고 순서대로.
