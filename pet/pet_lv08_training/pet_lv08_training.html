활동 1. 하은이의 훈련 3원칙

원칙
원칙내용
1. 즉시 보상잘한 3초 안에 간식 · 늦으면 이유 못 알아

활동 2. 하영이의 클리커·마커

도구

클리커 = 딸깍 소리 나는 훈련 도구. "이 순간 잘했어!"를 정확히 알려줌.

순서: 클리커(딸깍) → 즉시 간식. 강아지는 딸깍 소리 = 좋은 일 = 잘한 행동으로 학습.

대안: 말로 "옳지!" "굿보이"도 가능 (일관되면).

활동 3. 주은이의 "앉아" 훈련

앉아
  1. 간식을 강아지 코 앞에 든다
  2. 간식을 천천히 위로 올린다 → 자연히 엉덩이 내려앉음
  3. 앉는 순간 "앉아" 말하고 즉시 간식
  4. 10회 반복 → 다음 세션은 간식 없이 손짓만
  5. 성공률 80% 되면 말로만 "앉아" 시도

활동 4. 나머지 4가지 명령

명령
명령방법
엎드려앉은 상태에서 간식을 바닥으로 유도 → 엎드리면 보상
기다려앉은 상태에서 "기다려" → 1초 후 보상 → 점점 시간↑
이리와거리 두고 "이리와" + 밝은 목소리 → 오면 크게 칭찬 (제재 X)
안 돼 (No)단호한 목소리 · 잘못된 행동 즉시 · 대체 행동 유도
💡 "이리와" 함정 왔더니 혼내면 다음부턴 안 옴. 항상 칭찬·간식으로 맞이!

3. 배변 훈련·사회화

Step 3

활동 5. 주현이의 배변 훈련

배변
  1. 배변 패드를 고정된 자리에 (자주 이동 X)
  2. 배변 유도 시간: 기상 후·식사 후·놀이 후·잠 전 5회
  3. 패드로 안내 → 배변 성공 → 즉시 칭찬·간식
  4. 실수는 혼내지 않고 조용히 청소 (냄새 흔적 제거 중요)
  5. 2~4주면 대부분 익힘 (개체차)
❗ 실수 시 "얘는 왜 이래" 소리치면 몰래 숨어서 배변. 훈련 실패의 주범!

활동 6. 미정이의 사회화

사회화

사회화의 황금기 = 생후 3~16주. 이 시기 다양한 사람·소리·환경 경험이 평생 성격을 결정.

노출 대상방법
사람 (남녀·어린이·노인·모자·안경)간식 주며 인사 · 다양한 사람 만나기
다른 개·고양이접종 완료 후 · 짧은 놀이
소리 (진공청소기·초인종·차)작은 볼륨부터 점차 익숙해지기
장소 (도로·엘리베이터·병원)긍정 경험 만들기
다양한 표면 (풀·모래·타일)다양한 산책로
💡 사회화 부족 = 성견 되어 겁쟁이·공격성·짖음. 강아지 유치원·산책 클럽 활용!
