활동 1. 이 행동, 괜찮을까요?

O/X 5문항

공공장소에서 다음 행동이 O(괜찮음) 인지 X(안 됨) 인지 골라 이유를 짧게.

① 버스에서 이어폰 없이 유튜브 시청 ( O · X )  

② 지하철 노약자석 앞에 서 있는 어르신께 자리 양보 ( O · X )  

③ 도서관에서 친구와 목소리 낮춰 짧게 대화 ( O · X )  

④ 영화관에서 문자 확인용 폰 화면 켜기 ( O · X )  

⑤ 병원에서 진료실 앞 큰 소리 통화 ( O · X )
