활동 1. 위험 신호 찾기

O/X 5문항

위험 신호가 있으면 X, 없으면 O. 어떤 신호인지 짧게 써요.

① "안녕! 게임 잘하네~ 다음에 파티하자~" ( O · X )  

② "너 몇 살이야? 학교 어디야? 놀러 갈게" ( O · X )  

③ "우리 오빠·언니 하자. 부모님한테는 말하지 마" ( O · X )  

④ "옷 이쁘겠다. 셀카 보내 봐. 상반신도~" ( O · X )  

⑤ "만나서 얘기하자. 우리 집으로 오면 편해" ( O · X )
