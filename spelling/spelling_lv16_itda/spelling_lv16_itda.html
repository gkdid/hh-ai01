  • 분실물 신고서·일기에서 정확히 골라 쓴다.

📚 "잊다"와 "잃다"의 차이

1쪽 · 규칙
잊다는 머릿속에서 사라지는 일(기억 X), 잃다는 내 손에서 사라지는 일(물건·사람·기회 X)!
구분 잊다 (기억이 사라짐) 잃다 (놓치거나 잃어버림)
대상 추억·약속·이름·비밀번호 (마음) 지갑·핸드폰·친구·기회 (물건·사람)
바꿔 넣기 "기억이 안 나다" "잃어버리다"
예 약속을 잊고 안 갔다 · 이름을 잊었다 지갑을 잃어버렸다 · 친구를 잃었다
💡 암기 팁: "잊다" = 기억(마음) — 드롭! · "잃다" = 물건 — ㅎ 받침 = "허! 어디 갔지?"

활동 1. 잊다 / 잃다 골라 쓰기

8문항

① 어제 미정이 생일을 완전히 (잊 / 잃) 어버렸다.

② 지하철에서 우산을 (잊 / 잃) 어버렸다.

③ 그 친구의 이름을 자꾸 (잊 / 잃) 는다.

④ 게임에 빠져서 시간 개념을 (잊 / 잃) 었다.

⑤ 아르바이트 첫날, 자신감을 (잊 / 잃) 지 않으려 했다.

⑥ 비밀번호를 (잊 / 잃) 어서 로그인이 안 된다.

⑦ 도서관에서 학생증을 (잊 / 잃) 어버렸다.

⑧ 좋은 기회를 (잊 / 잃) 지 말자.

활동 2. 문장 완성 (활용형까지)

6문항

① 나는 어제 우산을   어버렸다. (놓침)

② 나는 어제 숙제가 있다는 걸   어버렸다. (기억)

③ 주은이는 지갑을   지 않으려 노력한다.

④ 미정이는 약속을   적이 없다. (기억)

⑤ 신뢰를   으면 회복이 힘들다. (놓침)

⑥ 그 노래 가사를   어서 흥얼거리기만 했다. (기억)

활동 3. 카톡 첨삭

6군데

① 지갑 잊어버렸어 (물건 놓침) → 지갑  

② 어디서 잊었는지 (물건) → 어디서  는지

③ 이어폰 잊어버렸는데 (물건) → 이어폰  

④ 뭘 잃어 (기억) → 뭘  

⑤ 학원 시간도 잃고 (기억 못 함) → 학원 시간도  

⑥ 비밀번호도 잃어서 (기억) → 비밀번호도

🔁 복습 · 다시 확인하기 — 잊다 · 잃다

추가 1쪽 · 복습
오늘 배운 잊다 · 잃다를 고르기 · ○× · 고쳐 쓰기로 가볍게 다시 확인해요. 정답에 ○표 하세요.

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요. (잊다=기억이 안 남 / 잃다=가지고 있던 것이 없어짐)

① 숙제를 ( 잊 / 잃 )어버렸어.

② 지갑을 ( 잊 / 잃 )어버렸어.

③ 친구 이름을 ( 잊 / 잃 )지 마.

④ 열쇠를 어디서 ( 잊 / 잃 )었지?

⑤ 약속을 ( 잊 / 잃 )어서 미안해.

⑥ 자신감을 ( 잊 / 잃 )지 말자.

⑦ 비밀번호를 ( 잊 / 잃 )어서 못 들어갔어.

⑧ 길을 ( 잊 / 잃 )어 헤맸어.

⑨ 그때 일을 아직도 ( 잊 / 잃 )을 수 없어.

⑩ 소중한 친구를 ( 잊 / 잃 )지 않을게.

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

맞춤법이 맞으면 ○, 틀리면 ✕ 를 괄호 안에 쓰세요.

번호문장○ / ✕
①숙제를 잊어버렸어. 
②지갑을 잊어버렸어. 
③열쇠를 잃어버렸어. 
④친구 이름을 잃지 마. 
⑤자신감을 잊지 말자. 
⑥약속을 잊어서 미안해. 
⑦길을 잊어 헤맸어. 
⑧비밀번호를 잊어버렸어. 
💡 기억이면 → 잊, 물건·마음처럼 갖고 있던 것이 없어졌으면 → 잃!

활동 A3. 틀린 글자 찾아 바르게 고치기

5문항 · 고치기

문장에서 틀린 글자에 ○ 치고, 옆 칸에 바른 표기를 쓰세요.

번호문장바르게 고쳐 쓰기
①지갑을 잊어버렸어. 
②약속을 잃어버렸어. 
③길을 잊어서 늦었어. 
④자신감을 잊지 말자. 
⑤친구 생일을 잃어버렸어. 

활동 A4. 짝 찾기 — 뜻과 바른 표기 연결

6문항 · 연결

왼쪽 뜻·상황과 오른쪽 바른 표기를 선으로 이어 보세요.

뜻 · 상황바른 표기
① 까먹다 (기억 안 남)ⓐ 지갑을 잃다
② 가진 것이 없어짐ⓑ 잊다
③ 숙제를 까먹음ⓒ 길을 잃다
④ 지갑을 분실함ⓓ 잃다
⑤ 길을 못 찾음ⓔ 이름을 잊다
⑥ 이름을 떠올리지 못함ⓕ 숙제를 잊다
