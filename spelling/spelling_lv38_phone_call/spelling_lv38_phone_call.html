📞 주현이의 미용실 예약주현
안녕하세요, 이번 주 토요일 2시의 경우에는 예약 가능할까요? 컷하고 염색 할려고 해요. 지난번 담당 선생님께 뵈여고요. 금액은 카드로써 결제하겠읍니다.
📅 채원이의 통화 메모채원
사장님이 "토요일은 꽉 찼읍니다, 일요일 어떠세요?"라고 하데. 일요일 1시로 변경하기로 할께요. 혹시 몇 일 전에 취소하면 되는지 물어봐야 함.

활동 7. 나의 생활글 쓰기

4~5문장
📌 주제: 가고 싶은 가게에 전화로 예약하는 글 (장소·날짜·요청, 4~5문장)

✅ 다 쓴 뒤 스스로 점검!

  • ‘며칠(몇 일 X)’ 바르게 썼나요?
  • ‘봬요(뵈요 X) · -할게요(-할께요 X)’ 바르게 썼나요?
  • ‘-했습니다(-했읍니다 X)’ 바르게 썼나요?
  • ‘반드시(꼭) / 반듯이(곧게)’ 뜻 맞게 썼나요?
  • ‘학생으로서(자격) / 연필로써(수단)’ 구분해서 썼나요?
  • ‘-하려고(-할려고 X) · -이에요/-예요’ 바르게 썼나요?
  • ‘깨끗이(깨끗히 X) · 바람(바램 X)’ 바르게 썼나요?

🔁 복습 · 다시 확인하기 — 전화 통화 맞춤법

오늘 배운 전화 통화 맞춤법을 고르기 · ○× · 고쳐 쓰기로 가볍게 다시 확인해요. 정답에 ○표 하세요.

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요.

① 토요일 2시( 의 경우에는 / 에 ) 예약 가능할까요?

② 염색 ( 할려고 / 하려고 ) 해요.

③ 지난번 담당 선생님께 ( 뵈여고요 / 봬려고요 ).

④ 카드( 로써 / 로 ) 결제하겠습니다.

⑤ 토요일은 꽉 찼( 읍니다 / 습니다 ).

⑥ 사장님이 일요일 어떠냐고 하( 데 / 대 ).

⑦ 일요일 1시로 변경( 할께요 / 할게요 ).

⑧ ( 몇 일 / 며칠 ) 전에 취소하면 되나요?

⑨ ( 안년하세요 / 안녕하세요 ), 저 OO입니다.

⑩ ( 수고하새요 / 수고하세요 ), 전화 끊겠습니다.

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

맞춤법이 맞으면 ○, 틀리면 ✕ 를 괄호 안에 쓰세요.

번호문장○ / ✕
①안녕하세요, 예약 문의드립니다. 
②토요일 2시에 예약하려고 해요. 
③토요일은 꽉 찼읍니다. 
④일요일 어떠냐고 하데 (전달). 
⑤변경할께요. 
⑥며칠 전에 취소하면 됩니다. 
⑦알겠습니다, 감사합니다. 
⑧다음에 뵈려고요. 
💡 헷갈리면 하려고(할려고 X) · 할게요(할께요 X) · 봬요(뵈요 X)를 떠올려 보세요.
