📖 -이 vs -히 — 하다 붙여 보기

1쪽 · 규칙
부사를 만들 때 -이가 붙기도 하고 -히가 붙기도 해요. 헷갈리면 어근 뒤에 "-하다"를 붙여 봐요. 말이 되면 -히, 안 되면 -이!
🔵 -히 ( "-하다"가 붙음 )
어근 뒤에 -하다가 자연스럽게 붙는 낱말은 -히
· 조용히 (조용하다 ⭕)
· 정확히 (정확하다 ⭕)
· 부지런히 (부지런하다 ⭕)
· 열심히 (열심하다 → 관용)
· 급히 (급하다 ⭕)
· 솔직히 (솔직하다 ⭕)
🟠 -이 ( "-하다"가 안 붙음 )
-하다가 안 붙거나, 같은 말이 겹친 낱말(첩어)은 -이
· 깨끗이 (깨끗하다 → 원래 "깨끗이"가 표준)
· 곰곰이 (곰곰하다 ❌)
· 겹겹이 (첩어)
· 낱낱이 (첩어)
· 번번이 (첩어)
· 반듯이 (반듯하게, 똑바로)
💡 가장 쉬운 확인법 — 발음으로!
소리 내어 읽어 봐서 "히"로 들리면 -히, "이"로 들리면 -이예요.
· "조용ㅎ|이" 처럼 ㅎ가 확실히 들림 → -히
· "깨끄시"처럼 ㅎ가 안 들림 → -이
🔵 -히로 쓰는 자주 나오는 낱말

⚠ 주의: 반듯이(반듯하게, 똑바로) ↔ 반드시(꼭)는 완전히 다른 낱말! "반드시 오세요"의 반드시는 -이/-히 문제가 아니에요.

활동 1. -이 · -히 골라 쓰기

10문항

① 방을 깨끗( 이 / 히 ) 청소했다.

② 도서관에서는 조용( 이 / 히 ) 해야 한다.

③ 시간을 정확( 이 / 히 ) 지켜야 해.

④ 나는 매일 열심( 이 / 히 ) 공부한다.

⑤ 곰곰( 이 / 히 ) 생각해 봐야겠다.

⑥ 짐이 겹겹( 이 / 히 ) 쌓여 있었다.

⑦ 부지런( 이 / 히 ) 준비하니 여유가 있었다.

⑧ 이번엔 솔직( 이 / 히 ) 말할게.

⑨ 일일( 이 / 히 ) 확인하지는 않아도 돼.

⑩ 가만( 이 / 히 ) 있으니 눈이 저절로 감겼다.

📓 주은이의 오늘 일기

2쪽 · 실전
주은이가 쓴 일기예요. 빨간 표시가 있는 낱말이 -이인지 -히인지 확인해서 바르게 고쳐 봐요.
📝 주은이의 일기 2026년 9월 18일 · 흐림
아침에 알람을 못 듣고 조금 늦잠을 잤다. 그래서 오늘은 아침을 급이 먹고 학교로 뛰어갔다. 선생님이 오늘 시험 결과를 일일히 알려 주셨다. 나는 열심이 준비했지만, 결과가 만족스럽지 않았다.

점심시간에 미정이가 조용이 나에게 다가와서 "괜찮아?"라고 물어봐 줬다. 정말 고마웠다. 나는 솔직이 마음을 이야기했고, 미정이도 가만이 내 얘기를 들어 줬다.

집에 와서 방을 깨끗히 정리했다. 그리고 오늘 있었던 일을 곰곰히 생각해 봤다. 내일부터는 더 부지런이 살아야겠다. 그리고 매일 틈틈히 복습도 해야지!
