📖 -이 vs -히 — 하다 붙여 보기

1쪽 · 규칙
부사를 만들 때 -이가 붙기도 하고 -히가 붙기도 해요. 헷갈리면 어근 뒤에 "-하다"를 붙여 봐요. 말이 되면 -히, 안 되면 -이!
🔵 -히 ( "-하다"가 붙음 )
어근 뒤에 -하다가 자연스럽게 붙는 낱말은 -히
· 조용히 (조용하다 ⭕)
· 정확히 (정확하다 ⭕)
· 부지런히 (부지런하다 ⭕)
· 열심히 (열심하다 → 관용)
· 급히 (급하다 ⭕)
· 솔직히 (솔직하다 ⭕)
🟠 -이 ( "-하다"가 안 붙음 )
-하다가 안 붙거나, 같은 말이 겹친 낱말(첩어)은 -이
· 깨끗이 (깨끗하다 → 원래 "깨끗이"가 표준)
· 곰곰이 (곰곰하다 ❌)
· 겹겹이 (첩어)
· 낱낱이 (첩어)
· 번번이 (첩어)
· 반듯이 (반듯하게, 똑바로)
💡 가장 쉬운 확인법 — 발음으로!
소리 내어 읽어 봐서 "히"로 들리면 -히, "이"로 들리면 -이예요.
· "조용ㅎ|이" 처럼 ㅎ가 확실히 들림 → -히
· "깨끄시"처럼 ㅎ가 안 들림 → -이
🔵 -히로 쓰는 자주 나오는 낱말
  • 조용히
  • 정확히
  • 솔직히
  • 부지런히
  • 열심히
  • 가만히
  • 급히
  • 편히
  • 가득히
  • 꼼꼼히
  • 각별히
  • 영원히
  • 단단히
  • 철저히
  • 안녕히
  • 친절히
🟠 -이로 쓰는 자주 나오는 낱말
  • 깨끗이
  • 곰곰이
  • 일일이
  • 낱낱이
  • 번번이
  • 겹겹이
  • 다달이

⚠ 주의: 반듯이(반듯하게, 똑바로) ↔ 반드시(꼭)는 완전히 다른 낱말! "반드시 오세요"의 반드시는 -이/-히 문제가 아니에요.

활동 1. -이 · -히 골라 쓰기

10문항

① 방을 깨끗( 이 / 히 ) 청소했다.

② 도서관에서는 조용( 이 / 히 ) 해야 한다.

③ 시간을 정확( 이 / 히 ) 지켜야 해.

④ 나는 매일 열심( 이 / 히 ) 공부한다.

⑤ 곰곰( 이 / 히 ) 생각해 봐야겠다.

⑥ 짐이 겹겹( 이 / 히 ) 쌓여 있었다.

⑦ 부지런( 이 / 히 ) 준비하니 여유가 있었다.

⑧ 이번엔 솔직( 이 / 히 ) 말할게.

⑨ 일일( 이 / 히 ) 확인하지는 않아도 돼.

⑩ 가만( 이 / 히 ) 있으니 눈이 저절로 감겼다.

📓 주은이의 오늘 일기

2쪽 · 실전
주은이가 쓴 일기예요. 빨간 표시가 있는 낱말이 -이인지 -히인지 확인해서 바르게 고쳐 봐요.
📝 주은이의 일기 2026년 9월 18일 · 흐림
아침에 알람을 못 듣고 조금 늦잠을 잤다. 그래서 오늘은 아침을 급이 먹고 학교로 뛰어갔다. 선생님이 오늘 시험 결과를 일일히 알려 주셨다. 나는 열심이 준비했지만, 결과가 만족스럽지 않았다.

점심시간에 미정이가 조용이 나에게 다가와서 "괜찮아?"라고 물어봐 줬다. 정말 고마웠다. 나는 솔직이 마음을 이야기했고, 미정이도 가만이 내 얘기를 들어 줬다.

집에 와서 방을 깨끗히 정리했다. 그리고 오늘 있었던 일을 곰곰히 생각해 봤다. 내일부터는 더 부지런이 살아야겠다. 그리고 매일 틈틈히 복습도 해야지!

활동 2. 주은이의 일기 고쳐 쓰기

10군데

위 일기의 빨간 표시 10개가 맞는지 확인하고, 틀리면 바른 것을 써 봐요.

① 급이 먹고 → 급 

② 일일히 알려 → 일일 

③ 열심이 준비 → 열심 

④ 조용이 다가와서 → 조용 

⑤ 솔직이 이야기 → 솔직 

⑥ 가만이 들어 줬다 → 가만 

⑦ 깨끗히 정리 → 깨끗 

⑧ 곰곰히 생각 → 곰곰 

⑨ 부지런이 살아야 → 부지런 

⑩ 틈틈히 복습 → 틈틈

쓰기

🔁 복습 · 다시 확인하기 — -이 · -히

추가 1쪽 · 복습
오늘 배운 -이 · -히를 고르기 · ○× · 고쳐 쓰기로 가볍게 다시 확인해요. 소리 내어 읽으면서 "-이"로 끝나는지 "-히"로 끝나는지 확인해요!

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요.

① 방을 ( 깨끗이 / 깨끗히 ) 치웠다.

② 숙제를 ( 꼼꼼이 / 꼼꼼히 ) 확인해.

③ 길을 ( 똑똑이 / 똑똑히 ) 알려 줘.

④ 수업 시간엔 ( 조용이 / 조용히 ) 해요.

⑤ 반찬을 ( 솔직이 / 솔직히 ) 말하면 별로야.

⑥ 창문을 ( 반듯이 / 반듯히 ) 닫아 줘.

⑦ 매일 ( 열심이 / 열심히 ) 공부해요.

⑧ 음식을 ( 따뜻이 / 따뜻히 ) 데웠어.

⑨ 선생님 말씀을 ( 가만이 / 가만히 ) 들어요.

⑩ 책을 ( 틈틈이 / 틈틈히 ) 읽자.

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

맞춤법이 맞으면 ○, 틀리면 ✕ 를 괄호 안에 쓰세요.

번호문장○ / ✕
①방을 깨끗히 치웠다. 
②솔직히 말해 줄래? 
③부지런이 움직여야 해. 
④방을 따뜻이 데워 놨어. 
⑤의자에 반듯이 앉자. 
⑥특이 조심할게요. 
⑦문을 조용히 닫았다. 
⑧숙제를 꼼꼼이 했어. 
💡 발음해 봐요. "-이"로만 들리면 -이, "-히"로 들리면 -히!

활동 A3. 틀린 글자 찾아 바르게 고치기

5문항 · 고치기

번호문장바르게 고쳐 쓰기

②숙제를 꼼꼼이 확인했다. 
③매일 열심이 공부해요. 
④솔직이 말해도 돼?
