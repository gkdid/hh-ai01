📚 "맞히다"와 "맞추다"의 차이

1쪽 · 규칙
맞히다 = "정답을 맞게 하다", "과녁에 명중시키다" (하나의 목표를 맞게 함)
맞추다 = "여러 개를 서로 대조·비교·조립", "시간을 정하다" (여러 개가 서로 맞도록 함)
구분 맞히다 (정답·명중) 맞추다 (대조·조립·시간)
대상 정답 하나 · 과녁 하나 · 화살 답안지·시간·퍼즐·옷·리듬
바꿔 넣기 "정답을 맞게 하다", "명중시키다" "서로 대어보다", "일치시키다"
예 1 퀴즈 정답을 맞혔다 (o) 친구와 답안지를 맞춰봤다
예 2 과녁을 맞혔다 (명중) 시계를 정확히 맞췄다
💡 암기 팁: "맞히다" = 히(정답 히트) / "맞추다" = 추(서로 맞대어 추가). 정답 → 히트! 대조·조립 → 추가로 맞!

활동 1. 맞히다 / 맞추다 골라 쓰기

5문항

① 채원이가 퀴즈 정답을 (맞혔다 / 맞췄다).

② 시험 후 짝꿍과 답을 (맞혔다 / 맞췄다).

③ 알람 시간을 6시 30분에 (맞혔다 / 맞췄다).

④ 궁수가 과녁을 정확히 (맞혔다 / 맞췄다).

⑤ 옷과 신발 색을 서로 (맞혔다 / 맞췄다).

활동 2. 문장 완성 (활용형)

5문항

① 이번 시험, 몇 개나   어? (정답)

② 친구와 시간을   려고 전화했다. (약속)

③ 퍼즐 조각을 딱   었다. (조립)

④ 다트를 던져 과녁 한가운데를   다. (명중)

⑤ 시험지를 답지에   어 보자. (대조)

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요. (맞히다=정답·목표 적중 / 맞추다=서로 맞게 함·비교·조립)

① 퀴즈에서 정답을 ( 맞혔 / 맞췄 )어!

② 친구와 답안지를 ( 맞혔 / 맞췄 )어.

③ 과녁 가운데를 ( 맞혔 / 맞췄 )어.

④ 퍼즐을 다 ( 맞혔 / 맞췄 )어.

⑤ 간을 ( 맞히 / 맞추 )는 법을 배웠어.

⑥ 수수께끼 답을 ( 맞혀 / 맞춰 ) 봐.

⑦ 약속 시간에 ( 맞혀 / 맞춰 ) 왔어.

⑧ 둘이 입을 ( 맞혔 / 맞췄 )지?

⑨ 세 문제 모두 ( 맞혔 / 맞췄 )어!

⑩ 조립 설명서를 보고 ( 맞혔 / 맞췄 )어.

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

맞춤법이 맞으면 ○, 틀리면 ✕ 를 괄호 안에 쓰세요.

번호문장○ / ✕
①퀴즈 정답을 맞혔어. 
②퍼즐을 다 맞혔어. 
③과녁 중앙을 맞혔어. 
④약속 시간에 맞춰 왔어. 
⑤답을 친구와 맞혀 봤어. 
⑥두 문제를 맞혔어. 
⑦국 간을 맞혔어. 
⑧조립을 맞춰 완성했어. 
💡 정답·과녁 등 하나를 알아내거나 적중하면 → 맞히다. 여럿을 비교·조립·조절하면 → 맞추다.

활동 A3. 틀린 글자 찾아 바르게 고치기

5문항 · 고치기

문장에서 틀린 글자에 ○ 치고, 옆 칸에 바른 표기를 쓰세요.

번호문장바르게 고쳐 쓰기
①퍼즐을 다 맞혔어. 
②답을 친구와 맞혀 봤어. 
③정답을 세 개 맞췄어. 
④간을 잘 맞혔어. 
⑤과녁을 맞췄어. 

활동 A4. 짝 찾기 — 뜻과 바른 표기 연결

6문항 · 연결

왼쪽 뜻·상황과 오른쪽 바른 표기를 선으로 이어 보세요.

뜻 · 상황바른 표기
① 정답·목표를 적중함ⓐ 답을 맞추다

③ 퀴즈 정답을 알아맞힘ⓒ 정답을 맞히다
④ 답을 서로 비교함ⓓ 퍼즐을 맞추다
⑤ 퍼즐을 완성함ⓔ 맞추다
⑥ 과녁에 적중시킴ⓕ 과녁을 맞히다
