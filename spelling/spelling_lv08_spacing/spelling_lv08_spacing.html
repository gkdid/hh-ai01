📖 띄어쓰기의 기본 원칙

1쪽 · 규칙
한글 띄어쓰기는 낱말과 낱말을 띄어 쓰는 것이 원칙이에요. 다만 조사는 앞말에 붙여 써요. 처음엔 헷갈리지만 몇 가지 규칙만 알면 90%는 맞출 수 있어요.
✅ 규칙 1. 조사는 붙여 쓴다
조사(은/는/이/가/을/를/에서/에게/와/과 등)는 앞말에 딱 붙여 씀.
나 는 학교 에 갔다 나는 학교에 갔다
친구 와 함께 밥 을 먹었다 친구와 함께 밥을 먹었다
✅ 규칙 2. 의존명사는 띄어 쓴다
것·수·때·대로·뿐·만큼·듯·따름은 홀로 못 쓰는 명사. 앞말과 띄움.
할수있다 할 수 있다
먹을것같아 먹을 것 같아
✅ 규칙 3. 단위 명사는 띄어 쓴다
개·명·마리·번·살·시·년 등 세는 단위는 앞의 수와 띄움.
사과 다섯개 사과 다섯 개
두시간후에 두 시간 후에
✅ 규칙 4. -하다는 붙여 쓴다
명사 뒤 -하다는 붙임 (공부하다, 사랑하다, 청소하다).
공부 하다 공부하다
청소 했어 청소했어

💡 헷갈릴 땐 이렇게! "이 낱말이 혼자서도 문장에서 쓸 수 있나?" 스스로 물어봐요. 혼자 못 쓰면 → 조사 → 붙임. 뜻 있는 낱말이면 → 띄움.

활동 A1. 바른 띄어쓰기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 띄어 쓴 것에 ○ 하세요. ( / 는 띄어쓰기 위치)

① ( 할 수 있다 / 할수있다 )

② ( 먹을 것 / 먹을것 )

③ ( 친구와 / 친구 와 ) 같이 갔어.

④ ( 하영이는 / 하영 이는 ) 책을 읽어.

⑤ ( 아는 것이 / 아는것이 ) 힘이다.

⑥ 배우는 ( 데 / 데 ) 하루가 걸려.

⑦ ( 한 개 / 한개 ) 더 주세요.

⑧ 그냥 ( 울 뿐 / 울뿐 )이야.

⑨ 책 ( 세 권 / 세권 )을 샀어.

⑩ ( 이것은 / 이것 은 ) 내 거야.

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

맞춤법이 맞으면 ○, 틀리면 ✕ 를 괄호 안에 쓰세요.

번호문장○ / ✕
①할수있다. 
②먹을 것이 많다. 
③친구와 같이 갔다. 
④책을 세권 샀어. 
⑤그럴 뿐이다. 
⑥나 는 집에 갔다. 
⑦공부하는 데 시간이 걸려. 
⑧아는것이 힘이다. 
💡 "것·수·때·뿐·데·만큼" 앞은 띄어! "-은/는/이/가/을/를" 조사는 붙여!
