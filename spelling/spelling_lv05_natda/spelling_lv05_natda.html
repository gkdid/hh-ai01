📖 낫다 vs 났다 vs 낳다

1쪽 · 세 낱말 구분
발음이 [낟따] · [낟따] · [나타]로 비슷하지만 뜻이 완전히 달라요. 잘못 쓰면 의미가 크게 바뀌는 낱말이니 확실히 익혀 봐요.
🟢 낫다
① 병이 회복되다
② 더 좋다
  • 감기가 낫다 (= 회복)
  • 빨리 나아! (감기가 나아라)
  • 다 나았어요 (회복)
  • 이게 저것보다 낫다 (더 좋다)
  • 차라리 이게 낫지 (더 좋다)
🟠 났다
"나다"의 과거형
(생기다·태어나다)
  • 화가 났다 (감정 생김)
  • 사고가 났어 (일 생김)
  • 여드름이 났어 (생김)
  • 불이 났다 (발생)
  • 1등이 났다 (배출됨)
🔴 낳다
아기·알을 낳다
결과를 만들다
  • 아기를 낳다
  • 닭이 알을 낳았어
  • 강아지가 새끼를 낳았어
  • 노력이 결과를 낳는다 (비유)
🚨 절대 헷갈리면 안 되는 병문안 문자!
❌ "빨리 낳아"
→ "아기를 낳아라!" 뜻이 됨 (큰일!)
⭕ "빨리 나아"
→ "감기가 낫기를 바라" (병문안 표현)
💡 구분 팁
· 병·감기·건강과 관련 → 낫다 ( 나아, 나았어, 나은 )
· 일·사건·감정·현상이 생겼을 때 → 났다 ( 났어, 났다, 나서 )
· 아기·알·새끼를 세상에 내놓을 때 → 낳다 ( 낳아, 낳았어, 낳은 )

활동 1. 알맞은 낱말 고르기

12문항

① 감기가 다 ( 났 / 낫 / 낳 )았어? 다행이다.

③ 우리 강아지가 새끼를 세 마리 ( 났 / 낫 / 낳 )았어.

④ 이 음식이 저것보다 ( 낫 / 났 )다.

⑤ 얼굴에 여드름이 ( 났 / 낫 / 낳 )어.

⑨ 열이 ( 났 / 낫 / 낳 )다가 이제 ( 났 / 낫 / 낳 )았어.

💌 To. 하은에게
하은아, 감기가 심하다며? 걱정 많이 낫어.
나도 지난주에 열이 낳아서 힘들었는데, 잘 쉬니까 금방 낳았어. 너도 곧 다 낳을 거야!

우리 반에서도 요즘 감기 걸린 애들이 많이 낳고 있어. 조심해야 할 것 같아. 하은이가 안 오니까 자리가 텅 비어서 마음이 아파. 빨리 낳아서 학교 오면 좋겠다!

약 잘 챙겨 먹고, 푹 쉬어. 조금이라도 몸이 낳아지면 나한테 연락해~ 그럼 진짜 빨리 낫기를 바랄게. 💖

활동 2. 카드에서 틀린 곳 고치기

7군데

위 카드의 빨간 표시 7개가 맞는지 확인해서 바르게 고쳐 봐요.

① "걱정 많이 낫어" → 걱정 많이  어

② "열이 낳아서" → 열이  아서

③ "금방 낳았어" (열이) → 금방  았어

④ "다 낳을 거야" (감기가) → 다   거야

⑤ "감기 걸린 애들이 많이 낳고" → 많이  고

⑥ "빨리 낳아서 학교 오면" → 빨리  아서

⑦ "몸이 낳아지면" → 몸이  아지면

💡 마지막 "낫기를 바랄게"는 사실 이건 맞는 표기예요!
