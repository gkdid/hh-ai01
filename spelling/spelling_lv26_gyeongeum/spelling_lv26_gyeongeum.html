🔤 사잇소리와 경음화의 원리

1쪽 · 원리
"국밥"이라고 쓰지만 [국빱]이라고 발음해요. "냇가"도 [내까/낻까]로 발음돼요. 발음이 강해지는 경음화가 일어나는데, 어떤 단어는 사이시옷(ㅅ)을 쓰고 어떤 단어는 쓰지 않아요.

💡 규칙 ① 사이시옷은 언제 쓸까?

합성 명사 + 앞말 받침 없음 + 뒷말 첫소리 된소리化 or ㄴ소리 덧남

· 내 + 가 → 냇가 [내까/낻까] ✓ 앞말 받침 X, 뒷말 [까]
· 나무 + 잎 → 나뭇잎 [나문닙] ✓ ㄴ소리 덧남
· 초 + 불 → 촛불 [초뿔/촏뿔] ✓
· 아래 + 층 → 아래층 ✗ 뒷말이 이미 거센소리(ㅊ)라서 사이시옷 X

💡 규칙 ② 경음화는 표기에 반영 X

받침이 있는 단일 어근 안에서 자연스레 된소리化 → 표기는 그대로

· 국밥 [국빱] ✓ 표기는 국밥 (국빱 ✗)
· 학교 [학꾜] ✓ 표기는 학교 (학꾜 ✗)
· 발전 [발쩐] ✓ 표기는 발전
· 봄바람 [봄빠람] ✓ 표기는 봄바람

🍜 시장 나들이 첨삭

2쪽 · 실전
하영·미정이가 시장에 나들이 갔어요. 두 친구의 대화·메모에서 사이시옷·경음화 오표기를 찾아 고쳐요.

하영: 시장에서 국빱 먹을까? 나는 시내까에 있는 분식집도 가고 싶어.

미정: 좋아! 저기 봄빠람 부니까 코 구멍이 시원하다. 참, 어제 촛불 켜고 저녁 먹었어. 로맨틱했지.

하영: 학꾜 앞에 새로 생긴 바다까 카페 봤어? 나문닙 데코가 예뻐.

미정: 안 봐 봤어. 대신 나는 등교길에 매일 지나가는 서점을 가려고.
