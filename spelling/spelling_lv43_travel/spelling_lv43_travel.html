빨간색으로 표시된 부분이 자주 틀리는 글자예요. 아래 규칙 상자를 보며 하나씩 고쳐 봐요!
L18'할려고 X / 하려고 O'
L28'~의 경우' 반복 자제
L3'-히/-이' (깨끗이 O·깨끗히 X, 친절히 O·친절이 X)
L21'봬요' O / '뵈요' X
🏨 주은이의 숙소 예약주은
안녕하세요, 다음 주 토·일 1박 예약할려고 합니다. 2인실 가능할까요? 체크인 시간의 경우에는 오후 3시 이후면 좋겠읍니다. 숙박비는 카드로써 결제할 수 있나요?
🧳 미정이의 여행 후기미정
숙소가 정말 깨끗히 잘 꾸며져 있었어요. 사장님도 친절히 안내해 주셨읍니다. 다음에 꼭 뵈요! 조식은 조금 아쉬울 것 같에요.

✅ 다 쓴 뒤 스스로 점검!

  • ‘며칠(몇 일 X)’ 바르게 썼나요?
  • ‘봬요(뵈요 X) · -할게요(-할께요 X)’ 바르게 썼나요?

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요.

① 숙소를 ( 예약할려고 / 예약하려고 ) 합니다.

② 체크인 시간 ( 은 / 의 경우에는 ) 오후 3시입니다.

③ 숙박비는 카드 ( 로써 / 로 ) 결제했어요.

④ 숙소가 정말 ( 깨끗히 / 깨끗이 ) 잘 꾸며져 있었어요.

⑤ 사장님께서 친절히 안내해 주셨 ( 읍니다 / 습니다 ).

⑥ 다음에도 꼭 ( 뵈요 / 봬요 )!

⑦ 조식은 조금 아쉬울 ( 것 같에요 / 것 같아요 ).

⑧ 다녀온 지 ( 몇 일 / 며칠 ) 됐어요.

⑨ 저녁은 현지 ( 음식에요 / 음식이에요 ).

⑩ 이 바다 사진은 제 ( 거에요 / 거예요 ).

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

맞춤법이 맞으면 ○, 틀리면 ✕ 를 괄호 안에 쓰세요.

번호문장○ / ✕
①1박 예약 할려고 합니다. 
②체크인 시간의 경우에는 3시 이후. 
③숙소가 깨끗이 잘 정리되어 있었어요. 
④다음에 또 뵈요! 
⑤숙박비는 카드로 결제했습니다. 
⑥조식은 조금 아쉬울 것 같아요. 
⑦다녀온 지 몇 일 됐어요. 
⑧이 바다 사진은 제 거예요. 
💡 "-하려고"는 항상 하려고! "할려고"는 없어요.
