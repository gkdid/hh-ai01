활동 7. 나의 생활글 쓰기

4~5문장
📌 주제: 지원하고 싶은 아르바이트 지원 문자 (학생+자격 '로서' 포함, 4~5문장)

✅ 다 쓴 뒤 스스로 점검!

  • ‘며칠(몇 일 X)’ 바르게 썼나요?
  • ‘봬요(뵈요 X) · -할게요(-할께요 X)’ 바르게 썼나요?
  • ‘-했습니다(-했읍니다 X)’ 바르게 썼나요?
  • ‘반드시(꼭) / 반듯이(곧게)’ 뜻 맞게 썼나요?
  • ‘학생으로서(자격) / 연필로써(수단)’ 구분해서 썼나요?
  • ‘-하려고(-할려고 X) · -이에요/-예요’ 바르게 썼나요?
  • ‘깨끗이(깨끗히 X) · 바람(바램 X)’ 바르게 썼나요?
  • ‘~것 같다 · ~의 경우 · ~을 통해서’ 반복 자제했나요?

오늘 배운 아르바이트 지원 맞춤법을 고르기 · ○× · 고쳐 쓰기로 가볍게 다시 확인해요. 정답에 ○표 하세요.

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요.

① 저는 고등학생 ( 으로써 / 으로서 ) 주말 아르바이트가 가능합니다.

② 성격은 ( 반듯이 / 반드시 ) 성실한 편이에요 (=곧게·올바르게).

③ 친절히 응대할 수 있( 읍니다 / 습니다 ).

④ 언제 면접 ( 뵈요 / 봬요 )?

⑤ 금요일 오후 3시( 의 경우에는 / 에는 ) 가능합니다.

⑥ 꼭 시간 지키겠( 읍니다 / 습니다 ).

⑦ ( 이녁서 / 이력서 )를 메일로 보내 드리겠습니다.

⑧ 주말 ( 근모 / 근무 ) 가능해요.

⑨ ( 시겁 / 시급 )은 얼마인가요?

⑩ 약속은 ( 반듯이 / 반드시 ) 지키겠습니다 (=꼭).

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

번호문장○ / ✕
①고등학생으로써 지원합니다. 
②이력서를 메일로 보내 드리겠습니다. 
③면접 때 봬요. 
④성실히 근무하겠읍니다. 
⑤약속은 반드시 지키겠습니다. 
⑥주말에만 근무할께요. 
⑦사장님께 지원 문의드립니다.
