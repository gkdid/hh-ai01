🔤 이/가 · 은/는의 규칙

1쪽 · 원리
"나는 학생이야" · "내가 왔어" — 왜 다를까요? 앞말 받침과 문장의 초점에 따라 조사가 달라져요.

💡 규칙 ① 받침에 따라 형태 선택

받침 있음 → 이 · 은  |  받침 없음 → 가 · 는

· 학생이 왔다 / 학생은 왔다 (받침 O)
· 하영이 왔다 / 하영은 왔다 (이름 뒤 - 하영에 받침 O)
· 예은이 왔다 / 예은은 왔다 (예은 받침 O)
· 미정이 왔다 / 미정은 왔다 (미정 받침 O)
· 채원이 왔다 / 채원은 왔다 (채원 받침 O)
· 학교가 좋다 / 학교는 좋다 (받침 X)

💡 규칙 ② 문장 초점의 차이

이/가 = 새 정보·강조  |  은/는 = 주제·대조

· "누가 왔어?" → "예은이 왔어" (누가? 예은!)
· "예은은?" → "예은은 도서관 갔어" (예은 얘기하자면)
· "나는 밥 먹고, 너는 국수 먹자" (대조)

상황이/가 (새 정보)은/는 (주제·대조)
이름 뒤예은이·미정이 왔다예은은·미정은 안 왔다
사물 뒤책이 있다책은 재밌다
내가 vs 나는"내가 할게" (내가!)"나는 할래" (나로 말하면)

활동 1. 받침 보고 조사 선택

5문항

① 하영( 이/가 ) 도서관에 갔다.

② 채원( 은/는 ) 공부를 열심히 한다.

③ 예은( 이/가 ) 대회에서 상을 받았다.

④ 학교( 이/가 ) 우리 집에서 멀다.

⑤ 카페( 은/는 ) 오후에 붐빈다.

활동 2. 문맥에 맞는 조사 (초점)

5문항

대화 흐름에 맞게 이/가 또는 은/는 골라요.

① Q. "누가 이겼어?" → A. "주현(   ) 이겼어."

② Q. "주현이 오늘 뭐 해?" → A. "주현(   ) 알바 갔어."

③ 사과(   ) 맛있고, 배(   ) 시원해. (대조)

④ Q. "어떤 게 좋아?" → A. "이 색(   ) 예뻐요." (강조)

⑤ 나(   ) 밥을 먹었고, 너(   ) 안 먹었잖아. (대조)

📔 일기 첨삭과 쓰기

2쪽 · 실전
예은이가 하영이 일기를 읽고, 자연스럽지 않은 조사를 표시했어요. 함께 고쳐 봐요.
📖 하영의 일기 (3월 5일)
오늘 나가 처음으로 카페에서 알바를 했다. 사장님가 친절하셨고, 손님가 많아서 정신이 없었다. 점심에는 예은이가 놀러 왔다. 예은이가 아이스티를 주문했다. 예은이가 앉은 자리는 창가였다. 퇴근할 때 사장님이 "수고했어요"라고 하셔서 기뻤다. 나가 이 알바를 잘할 수 있을까?

활동 3. 하영이 일기 첨삭

5군데

① 나가 처음으로 → 나  처음으로 힌트: "나+ㄴ=나는" or "내가"

② 사장님가 → 사장님  힌트: 받침 있음

③ 예은이가 놀러 왔다·아이스티를 주문·앉은 자리 (세 번 반복) → 두 번째부터는 주제(은)로 자연스러움
→ 예은이가 놀러 왔다. 예은이  아이스티를 주문했다. 예은이  앉은 자리는 창가였다.

④ 사장님이 → 이대로 O? (   )

⑤ 나가 이 알바를 잘할 수 있을까 →   알바를 잘할 수 있을까

구별 3원칙
① 받침 O → 이/은, 받침 X → 가/는
② "누가?" 답 → 이/가, "그 사람은?" → 은/는
③ 나는 주제, 내가 강조. "나가"는 없어요!

활동 4. 오늘의 일기 3문장 쓰기

쓰기

오늘 있었던 일을 3문장으로 써 봐요. 이/가와 은/는을 각각 1번 이상 자연스럽게 사용.
