📚 "든지"와 "던지"의 차이

1쪽 · 규칙
"~든지"는 선택·상관없음을 나타내요. "이것도 좋고 저것도 좋다"의 느낌!
"~던지"는 과거의 회상·놀라움을 나타내요. "그때 얼마나 그랬는지 몰라"의 느낌!
구분 -든지 (선택 · 상관없음) -던지 (과거 회상 · 감탄)
뜻 여럿 중에서 고르기, 무엇이 되어도 상관없음 과거에 그랬던 일을 떠올리기, 얼마나 그랬는지 감탄
바꿔 넣기 "~이든 ~이든", "~해도 상관없다" "~었을 정도로", "~었는지"
예 1 밥이든지 빵이든지 다 좋아 어제 얼마나 춥던지 감기 걸릴 뻔했어
예 2 뭐를 먹든지 네 마음이야 그 영화가 얼마나 슬프던지 계속 울었어
예 3 언제든지 연락해 지난주에 갔던 카페 기억나?
💡 암기 팁: "던"에는 ㅓ가 있어서 과거(었/었)와 짝! → "그랬던 때, 얼마나 좋던지".
"든"은 ㅡ → 둘 중 하나 든다(선택). → "이든 저든, 뭐든".

활동 1. 밑줄에 든지/던지 넣기

10문항

① 커피이  차이  상관없어. (선택)

② 어제 도서관이 얼마나 조용하 지 잠 올 뻔했어. (감탄)

③ 뭐가 되  넌 잘할 거야. (상관없음)

④ 그 영화가 얼마나 재미있 지 두 번 봤어. (과거)

⑤ 언제  오세요. (아무 때나)

⑥ 배가 얼마나 고프 지 라면을 두 개 먹었어. (과거·감탄)

⑦ 사과  딸기  다 좋아해. (선택)

⑧ 시험이 얼마나 어렵 지 30분 만에 지쳤어. (과거)

⑨ 걷  뛰  시간 맞춰 와. (상관없음)

⑩ 그 노래가 얼마나 좋 지 계속 들었어. (감탄)

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요.

① 뭐를 먹( 든지 / 던지 ) 네 마음이야.

② 어제 얼마나 춥( 든지 / 던지 ) 손이 얼었어.

③ 커피( 든지 / 던지 ) 차( 든지 / 던지 ) 괜찮아.

④ 그 영화가 얼마나 슬프( 든지 / 던지 ) 눈물이 났어.

⑤ 언제( 든지 / 던지 ) 연락해.

⑥ 지난주에 갔( 든 / 던 ) 카페 기억나?

⑦ 걷( 든지 / 던지 ) 뛰( 든지 / 던지 ) 빨리 와.

⑧ 배가 얼마나 고프( 든지 / 던지 ) 두 그릇을 먹었어.

⑨ 사과( 든지 / 던지 ) 딸기( 든지 / 던지 ) 다 좋아해.

⑩ 그 노래가 얼마나 좋( 든지 / 던지 ) 반복해 들었어.

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

맞춤법이 맞으면 ○, 틀리면 ✕ 를 괄호 안에 쓰세요.

번호문장○ / ✕
①나는 뭐든지 다 잘 먹어. 
②어제 얼마나 추웠든지 몰라. 
③커피든지 차든지 상관없어. 
④지난번에 봤든 영화 다시 보자. 
⑤언제던지 도와줄게. 
⑥그 음식이 얼마나 짜던지 물을 다 마셨어. 
⑦뛰던지 걷던지 네 맘대로 해. 
⑧작년에 살던 집이 그리워. 
💡 어제·그때가 보이면 던, 아무거나·상관없음이면 든!

활동 A3. 틀린 글자 찾아 바르게 고치기

번호문장바르게 고쳐 쓰기

②어제 얼마나 춥든지 몰라. 
③커피던지 차던지 상관없어. 
④지난번에 갔든 카페 다시 가자. 
⑤언제던지 놀러 와도 돼.
