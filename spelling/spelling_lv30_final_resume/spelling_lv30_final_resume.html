활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요.

① 학생 ( 으로써 / 으로서 ) 2년간 알바를 했다.

② 익힌 ( 사람이에요 / 사람입니다 ).

③ ( 깨끗히 / 깨끗이 ) 정리했다.

④ 손님에게 ( 친절이 / 친절히 ) 응대했다.

⑤ ( 저의 경우에는 / 저는 ) 책을 좋아합니다.

⑥ 봉사활동 ( 을 통해서 / 에서 ) 배웠습니다.

⑦ 좋아했( 읍니다 / 습니다 ).

⑧ 내일 ( 뵈요 / 봬요 )!

⑨ ( 몇 일 / 며칠 ) 안에 연락드리겠습니다.

⑩ 최선을 ( 다하지 않을 수 없습니다 / 다하겠습니다 ).
