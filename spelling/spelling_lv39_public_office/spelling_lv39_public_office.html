빨간색으로 표시된 부분이 자주 틀리는 글자예요. 아래 규칙 상자를 보며 하나씩 고쳐 봐요!

L29'몇 일 X / 며칠 O'
L22'-했읍니다 X', '-할께 X'
L15'반드시(꼭)' / '반듯이(곧게)'
📄 하은이의 민원 신청서하은
본인은 학생으로써 학생증 재발급을 신청하고자 합니당. 분실 신고는 지난 몇 일 전에 완료하였읍니다. 발급은 반듯이 10일 이내에 부탁드립니다.
🧾 미정이의 전입 신고 메모미정
전입 신고을 하러 왔습니다. 담당 공무원이 "서류가 하나 부족합읍니다"라고 하데. 그래서 집의 경우에는 다시 가서 등본을 가져오기로 할께요.

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요.

① 본인은 학생 ( 으로써 / 으로서 ) 재발급을 신청합니다.

② 신청하고자 합니( 당 / 다 ).

③ 지난 ( 몇 일 / 며칠 ) 전에 분실 신고를 했어요.

④ 발급은 ( 반듯이 / 반드시 ) 10일 이내 부탁드립니다.

⑤ 전입 신고( 을 / 를 ) 하러 왔습니다.

⑥ 공무원이 서류가 부족하다고 하( 데 / 대 ).

⑦ 완료하였( 읍니다 / 습니다 ).

⑧ 등본을 가져오기로 ( 할께요 / 할게요 ).

⑨ 번호표를 ( 뽐고 / 뽑고 ) 기다리세요.

⑩ ( 발금 / 발급 ) 창구로 가세요.

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×

맞춤법이 맞으면 ○, 틀리면 ✕ 를 괄호 안에 쓰세요.

번호문장○ / ✕
①등본 한 통 발급 부탁드립니다. 
②담당자를 뵙고 싶습니다. 
③분실 신고는 며칠 전에 완료했습니다. 
④학생으로써 신청합니다. 
⑤서류가 하나 부족합니다. 
⑥전입 신고을 하러 왔습니다. 
⑦10일 안에 반듯이 발급 부탁드립니다. 
⑧알겠습니다, 감사합니다. 
💡 헷갈리면 으로서(자격) · 를(목적격) · 반드시(꼭)를 떠올려 보세요.

활동 A3. 틀린 글자 찾아 바르게 고치기

5문항 · 고치기

문장에서 틀린 글자에 ○ 치고, 옆 칸에 바른 표기를 쓰세요.

번호문장바르게 고쳐 쓰기
①학생으로써 신청합니다. 
②지난 몇 일 전에 신고했어요. 
③완료하였읍니다. 
④전입 신고을 하러 왔습니다. 
⑤공무원이 부족하다고 하데.
