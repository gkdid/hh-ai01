📖 며칠 · 어떻게 · 어떡해

1쪽 · 규칙
카톡·문자에서 자주 실수하는 세 낱말이에요. 하나씩 확실히 익혀요.
🔑 필살기 ① — 며칠은 언제나 며칠!
✅ 며칠 (며칠 만에, 며칠째, 며칠 후)
❌ 몇 일 · 몇일 (모두 틀린 표기!)
"며칠"은 이미 굳어진 낱말이라 항상 그대로 써요.
"몇 년 · 몇 월"은 띄어 쓰고 이렇게 쓰지만, "며칠"만은 예외!
🔵 어떻게 (= 어떠하게)
방법·상태를 묻거나 나타내요. 뒤에 다른 말이 이어져요.
  • 이거 어떻게 해? (방법)
  • 어떻게 지냈어? (상태)
  • 어떻게 알았어? (방법)
  • 공부는 어떻게 하고 있어? (방법)
  • 넌 이걸 어떻게 생각해? (의견)
🔴 어떡해 (= 어떻게 해)
걱정·감탄·큰일 났을 때. 문장 끝에 옴, 그 자체로 완성돼요.
  • 나 이제 어떡해! (걱정)
  • 이걸 어떡해... (당황)
  • 아, 어떡해 ㅠㅠ (감탄)
  • 지각인데 어떡해! (큰일)
  • 망했다, 어떡해! (당황)
💡 구별 팁 — "어떡해"는 문장 끝!
· 그 자체로 완성된 감탄문이면 → 어떡해
· 뒤에 다른 말이 이어지면 → 어떻게
· 예: "지각인데 어떡해!" (끝, 감탄) / "지각인데 어떻게 하지?" (뒤에 "하지" 붙음)

활동 1. 며칠·어떻게·어떡해 골라 쓰기

10문항

① 시험이 ( 며칠 / 몇 일 ) 남았지?

② 이 문제 ( 어떻게 / 어떡해 ) 풀어?

③ 아, 늦었어! 나 ( 어떻게 / 어떡해 )!

④ 방학이 ( 며칠 / 몇 일 ) 안 남았어.

⑤ ( 어떻게 / 어떡해 ) 지내니? 오랜만이야!

⑥ 지갑을 잃어버렸어. ( 어떻게 / 어떡해 ) ㅠㅠ

⑦ 그 소식을 ( 어떻게 / 어떡해 ) 알았어?

⑧ ( 며칠 / 몇 일 ) 만에 만나는 거지?

⑨ 이걸 ( 어떻게 / 어떡해 ) 해야 될지 모르겠어.

⑩ 아 진짜 ( 어떻게 / 어떡해 )! 완전 망했어!
