📖 왠 vs 웬 — 필살기 하나면 OK!

1쪽 · 규칙
왠과 웬은 발음도 비슷하고 뜻도 비슷해 보여요. 하지만 단 하나의 규칙만 기억하면 절대 안 헷갈려요!
🔑 필살기
"왠지"만 "왠"!
나머지는 모두 "웬"!
왠지는 "왜인지"의 준말이에요. → "왜인지"로 바꿔 봐서 말이 되면 "왠지"
🟠 왠 (= 왜인지의 준말)
오직 "왠지" 하나만! "이유는 잘 모르겠지만~"이란 뜻.
· 왠지 오늘 손님이 많다. (= 왜인지)
· 왠지 눈물이 나. (= 왜인지)
· 왠지 기분이 좋아. (= 왜인지)
🟢 웬 (그 외 모두)
"어찌 된", "어떠한"의 뜻. 명사 앞에 붙어요.
· 웬일이야! (어찌된 일)
· 웬 사람이 왔어. (어떠한 사람)
· 웬만하면 그렇게 해. (어지간하면)
· 웬걸, 다 그런 건 아니야.
· 웬일로 이렇게 일찍?
💡 확인법 — "왜인지"로 바꿔 봐요
· 그 자리에 "왜인지"를 넣어 자연스러우면 → 왠지
· "왜인지"가 어색하면 → 웬

예시
① "( 왠 / 웬 )지 오늘 손님이 많네" → "왜인지 오늘 손님이 많네" ⭕ → 왠지
② "( 왠 / 웬 )일로 왔어?" → "왜인지일로 왔어?" ❌ → 웬일

10문항

⑥ ( 왠 / 웬 )걸, 그건 오해였어.

⑨ ( 왠 / 웬 )만한 일에는 놀라지 않는다.

⑩ ( 왠 / 웬 )일이니, 이 시간에?

활동 A1. 바른 표기에 ○ 하기

10문항 · 고르기

두 개 중 바르게 쓴 것에 ○ 하세요.

① 오늘따라 ( 왠지 / 웬지 ) 기분이 좋아.

② 이게 ( 왠 / 웬 ) 떡이야?

③ 그 사람은 ( 왠만하면 / 웬만하면 ) 괜찮아.

④ 저녁에 ( 왠 / 웬 ) 손님이 왔네.

⑤ ( 왠일 / 웬일 )로 일찍 왔어?

⑥ ( 왠지 / 웬지 ) 모르게 눈물이 났어.

⑦ ( 왠만한 / 웬만한 ) 일은 혼자 해.

⑧ 아침부터 ( 왠 / 웬 ) 비가 이렇게 와?

⑨ 그런 건 ( 왠만해선 / 웬만해선 ) 안 돼.

⑩ 길에서 ( 왠 / 웬 ) 사람이 말을 걸었어.

활동 A2. 바르면 ○, 틀리면 ✕

8문항 · ○×
