2. 주문하고 계산하기

Step 2

활동 1. 하은이가 혼자 주문

1인 주문

하은이는 바닐라라떼 1잔 + 크로와상 1개를 시켰어요.

총액 = 5,000 + 3,500 = 8,500 원

10,000원을 냈다면 거스름돈 = 원

활동 2. 하영이의 옵션 주문

옵션

하영이는 아메리카노를 시키면서 사이즈 업(+500)과 샷 추가(+500)를 골랐어요.

3,500 + 500 + = 원

💡 팁 옵션은 기본 가격에 더해서 계산해요. 시럽·휘핑은 무료라서 안 더해도 돼요.

활동 4. 주현이의 여러 잔 주문

여러 잔

주현이가 친구들과 아메리카노 3잔을 시켰어요.

3,500 × 3 = 원

20,000원을 냈다면 거스름돈 = 원

4. 종합 — 하은스 카페 알바 체험

Step 4
💡 역할 오늘은 여러분이 하은스 카페의 알바 직원이 됐다고 생각해봐요. 손님이 주문하면 총액과 거스름돈을 알려줘야 해요.

활동 7. 손님 A — 하영

알바 계산

주문: 카페라떼 1잔(사이즈업), 크로와상 2개

총액 = (4,500 + 500) + (3,500 × 2) = 원

손님이 15,000원을 냈어요. 거스름돈 = 원

활동 8. 손님 B — 예은

알바 계산

주문: 아메리카노 2잔(각 샷 추가), 머핀 1개

총액 = (3,500 + 500) × 2 + 3,000 = 원

손님이 10,000원 + 1,000원 3장을 냈어요. 총 낸 돈 = 원 · 거스름돈 = 원

활동 9. 손님 C — 미정 (여러 잔)

알바 계산

주문: 딸기 스무디 2잔, 치즈케이크 1조각, 쿠키 3개

총액 = (6,000 × ) + 6,500 + (2,500 × ) = 원

손님이 3만원을 냈어요. 거스름돈 = 원
