🚄 KTX·비행기 시간 계산

1쪽 · 이동 수단 이해
KTX나 비행기는 출발 시각이 정해져 있어요. 늦으면 탈 수 없으니 여유 있게 도착해야 해요. 비행기는 특히 탑승 수속(체크인)과 보안 검사 시간을 꼭 계산해야 해요.
예은예은이는 부산 여행을 가요. 8시 KTX를 타면 부산역에 10시 40분에 도착해요. 8:00 → 10:00 = 2시간, 10:00 → 10:40 = 40분. 총 2시간 40분 걸려요!

🗺️ 하루 여행 일정 짜기

2쪽 · 응용·계획
여행 일정은 이동 → 활동 → 이동 → 활동이 반복돼요. 각 활동에 걸리는 시간과 이동 시간을 계산해서 다음 활동 시작 시각을 정해요.
