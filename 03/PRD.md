# 링크나무 PRD

## 1. 개요
- **서비스명**: 링크나무
- **한 줄 설명**: 내 모든 링크를 한 페이지에 모아두고, 하나의 URL로 공유하는 서비스
- **타깃 사용자**: SNS에 여러 링크를 공유하고 싶은 개인 창작자, 개발자, 프리랜서

## 2. 배경 / 문제
Instagram, Twitter(X), TikTok 등 대부분의 SNS는 프로필 바이오에 **단 하나의 URL**만 허용한다. 하지만 창작자·개발자·프리랜서는 YouTube, 블로그, 포트폴리오, 숍, 문의 폼 등 **여러 채널**을 동시에 운영한다. 매번 바이오 링크를 바꾸거나 "링크는 댓글 참고" 식으로 안내하는 불편을 해소하기 위해, 모든 링크를 모아 공유할 수 있는 **허브 페이지**가 필요하다.

## 3. 목표 / 비목표

### 목표
- 사용자가 **5분 이내**에 자신의 링크 모음 페이지를 생성할 수 있다.
- 공유용 URL이 짧고 기억하기 쉽다 (예: `linknamu.co/sm`).
- 운영자가 **어떤 링크가 가장 많이 클릭됐는지** 한눈에 확인할 수 있다.

### 비목표 (MVP 범위 외)
- 유료 구독 / 결제
- 커스텀 도메인 연결
- 지역·디바이스·레퍼러 등 상세 분석
- 다국어 UI (초기엔 한국어 단일)

## 4. 타깃 사용자

| 페르소나 | 니즈 | 통합할 링크 예시 |
|---|---|---|
| 개인 창작자 (일러스트레이터·유튜버) | 포트폴리오·SNS·판매처를 한 번에 안내 | YouTube, Instagram, 작가노트, 굿즈 숍 |
| 개발자 | 개발 활동 전반을 보여주기 | GitHub, 기술 블로그, LinkedIn, 이력서 PDF |
| 프리랜서 | 문의·작업 확인 창구 통합 | 포트폴리오 사이트, 문의 폼, 캘린더 예약, 결제 링크 |

## 5. 핵심 기능 (MVP)

### 5.1 프로필
- **이름** (필수)
- **한 줄 소개** (선택, 최대 80자)
- **프로필 사진** (선택, 미지정 시 이름 첫 글자 이니셜 아바타)

### 5.2 링크 카드
- 카드 1장 = **제목 + URL + 아이콘**(선택).
- 카드 전체가 클릭 가능하며, 새 탭으로 이동.
- **드래그 앤 드롭**으로 순서 변경.
- 각 카드별 **활성/비활성 토글** (삭제하지 않고 임시로 숨기기).

### 5.3 클릭 수 집계
- 방문자가 링크 카드를 클릭하면 **익명 이벤트**를 서버에 기록.
- 운영자 대시보드에서 **링크별 총 클릭 수**를 테이블로 조회.
- 기간 필터: 전체 / 최근 30일 / 최근 7일.
- 같은 세션 내 중복 클릭은 1회로 집계 (봇·스팸 완화).

## 6. 유저 플로우
1. **가입/로그인** (이메일 + 비밀번호 또는 소셜 로그인)
2. **사용자명 선택** → `linknamu.co/<사용자명>` 자동 할당
3. 프로필 작성 (이름·소개·사진)
4. **링크 추가** (제목·URL, 아이콘 자동 추론)
5. 공유 URL 복사 → SNS 바이오에 붙여넣기
6. 방문자가 공개 페이지에서 링크 클릭
7. 운영자 대시보드에 클릭 수 반영

## 7. 요구사항

### 기능 요구사항 (FR)
| ID | 설명 |
|---|---|
| FR-1 | 이메일+비밀번호 가입/로그인, 비밀번호 재설정 |
| FR-2 | 공개 프로필 페이지 (`/<사용자명>`), 미로그인 상태로 열람 가능 |
| FR-3 | 링크 CRUD, 드래그로 순서 변경, 활성/비활성 토글 |
| FR-4 | 링크 클릭 이벤트 수집 (익명, 세션 중복 제거) |
| FR-5 | 운영자 대시보드: 링크별 클릭 수 + 기간 필터 |
| FR-6 | 공유 URL 한 번에 복사 버튼 |

### 비기능 요구사항 (NFR)
- 공개 페이지 **초기 로드 2초 이내** (3G 기준 LCP ≤ 2.5s).
- 모바일 반응형 (가장 많은 트래픽이 모바일 바이오 링크에서 유입).
- 접근성: 키보드 탐색, 적절한 ARIA 라벨, 색 대비 WCAG AA.
- 가용성: 월 가동률 99.5% 이상.

## 8. 성공 지표 (North Star & 보조 지표)
- **North Star**: 월간 공개 페이지 조회수(= 바이오 링크 유입)
- 가입 완료율 (방문 → 가입)
- 1인당 평균 등록 링크 수
- 평균 클릭률 CTR (조회 대비 링크 클릭)
- 7일 리텐션 (가입 후 7일 이내 재방문/편집 비율)

## 9. 마일스톤

| 단계 | 범위 | 기간 |
|---|---|---|
| M1 | 가입/로그인, 프로필 + 링크 카드 공개 페이지 | 2주 |
| M2 | 클릭 집계 + 운영자 대시보드 | 1주 |
| M3 | 공유 UX 다듬기, 테마(라이트/다크) 선택 | 1주 |

## 10. 리스크 & 대응
- **사용자명 선점·상표 분쟁**: 예약어 리스트(브랜드명·비속어·공식 경로) 사전 차단, 신고 접수 창구 운영.
- **봇/중복 클릭으로 지표 왜곡**: 세션 쿠키 기반 중복 제거, 비정상 트래픽 모니터링.
- **스팸/피싱 링크 삽입**: 외부 URL 블랙리스트 체크, 신고 기능, 수동 심사.
- **데이터 유실(클릭 로그)**: 비동기 큐 + 재시도, 일배치 백업.

## 11. 열린 질문 (추후 확정)
- 사용자명 변경 허용 여부와 변경 시 기존 URL 처리 (301 리다이렉트 유지 기간)
- 무료 플랜의 링크 개수 제한 (없음 / 10개 / 20개?)
- 테마/배경 커스터마이즈를 MVP에 포함할지 M3로 미룰지
